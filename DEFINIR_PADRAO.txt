📋 PASSO A PASSO:


┌────────────────────────────────────────────────────────────────────────────┐
│ OPÇÃO 1: AUTOMÁTICA (Recomendado)                                         │
└────────────────────────────────────────────────────────────────────────────┘

Execute este comando no terminal:

    cd /home/caio/Downloads/cosmic-term
    bash definir-como-padrao.sh


Isso vai:
  ✓ Instalar o COSMIC Terminal em /usr/local/bin/
  ✓ Instalar os ícones e arquivos .desktop
  ✓ Registrar como alternativa do sistema
  ✓ Definir como terminal padrão
  ✓ Configurar no GNOME


┌────────────────────────────────────────────────────────────────────────────┐
│ OPÇÃO 2: MANUAL (Passo a passo)                                           │
└────────────────────────────────────────────────────────────────────────────┘

1️⃣  Instalar no sistema:

    sudo cp target/release/cosmic-term /usr/local/bin/
    sudo cp res/com.system76.CosmicTerm.desktop /usr/share/applications/


2️⃣  Registrar como alternativa:

    sudo update-alternatives --install /usr/bin/x-terminal-emulator \
         x-terminal-emulator /usr/local/bin/cosmic-term 100


3️⃣  Definir como padrão:

    sudo update-alternatives --set x-terminal-emulator /usr/local/bin/cosmic-term


4️⃣  Configurar no GNOME (opcional):

    gsettings set org.gnome.desktop.default-applications.terminal exec 'cosmic-term'


5️⃣  Atualizar cache:

    sudo update-desktop-database
